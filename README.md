# Yapply

A responsive language-practice room interface built with Next.js, React, and TypeScript. Montserrat is bundled locally through Fontsource.

## Run

```sh
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run build` for a production build and `npm run typecheck` for TypeScript validation.

This is an interface prototype: portraits are sample Unsplash images, media buttons change preview state, captions are samples, and reports stay local. No microphone/camera access, LiveKit connection, recording, speech scoring, or backend is enabled. The practice button starts a two-minute demo timer.
